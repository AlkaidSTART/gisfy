# GisFy — 产品需求文档 (PRD)

> 版本：v2.0
> 更新时间：2026-05-23
> 项目类型：七牛云黑客松 · 3天速通
> 技术栈：Next.js 16 + React 19 + TailwindCSS v4 + shadcn/ui v4 + Vercel AI SDK v6 + TypeScript 6

---

## 1. 产品概述

### 1.1 产品定位

**GisFy** 是一个面向2D游戏开发者的 AI 游戏素材生成工具。用户通过输入文字描述或选择参数，即可高效、低成本地生成可直接用于主流2D游戏引擎（Unity / Godot / RPG Maker）的游戏素材。

### 1.2 产品口号

> **「描述即素材，输入即资产」**

### 1.3 目标用户

| 用户画像 | 痛点 | 使用场景 |
| :--- | :--- | :--- |
| 🎮 独立游戏开发者 | 没钱请美术，自己画不好 | 快速生成角色、场景、道具原型 |
| 🏢 小游戏团队 | 美术资源紧缺，迭代快 | 批量生成素材做原型验证 |
| 🎒 游戏开发学习者 | 练习做游戏但不会画画 | 生成素材用于个人项目 |

### 2.2 功能清单

#### 🔴 P0 — 必备功能

| 功能 | 描述 | 验收标准 |
| :--- | :--- | :--- |
| **文字→素材生成** | 用户输入文字描述，AI 生成对应素材图片 | ✅ 支持中文/英文输入 ✅ 生成时间 ≤ 15s |
| **风格选择** | 用户可选择生成风格：像素风 / 扁平风 / 日系动漫风 | ✅ 三种风格切换流畅 ✅ 同描述不同风格效果可区分 |
| **透明背景导出** | 生成的素材默认透明背景（PNG），可直接导入游戏引擎 | ✅ 导出为 RGBA PNG ✅ 背景透明无锯齿 |
| **素材预览** | 生成后在页面展示大图预览 | ✅ 支持放大/缩小查看 ✅ 显示生成参数（风格/尺寸/耗时） |
| **七牛 Kodo 存储** | 生成的素材自动上传至七牛对象存储 | ✅ 上传成功返回 URL ✅ 通过 CDN 加速访问 |

#### 🟡 P1 — 建议功能

| 功能 | 描述 | 验收标准 |
| :--- | :--- | :--- |
| **Spritesheet 生成** | 将多个相关素材合成为一张精灵图（如角色行走四帧） | ✅ 支持自定义行列数 ✅ 导出后附带帧信息（JSON） |
| **素材历史** | 查看用户历史上生成的素材列表 | ✅ 按时间倒序排列 ✅ 支持重新下载/删除 |
| **下载功能** | 一键下载生成的素材到本地 | ✅ 单张 PNG 下载 ✅ Spritesheet PNG + JSON 打包下载 |
| **简易参数调节** | 控制生成图片的宽高、数量等 | ✅ 支持 64/128/256/512 尺寸 ✅ 支持 1/4/9 宫格批量生成 |
| **Seed 控制** | 固定随机种子，支持同一 prompt 复现相同结果 | ✅ 可手动输入 Seed ✅ 不填则随机生成 |
| **负面提示词** | 排除不想要的元素（如「不要武器」「不要背景」） | ✅ 支持自定义负面词 |

#### 🟢 P2 — 扩展功能（看时间）

- Tilemap 瓦片地图生成（可无缝拼接）
- UI 元素生成（按钮、图标、血条）
- 特效素材生成（火焰、爆炸）
- 用户注册/登录（七牛临时令牌）

## 3. 风格与模型策略

### 3.1 支持的风格

| 风格 | 视觉特征 | 适用游戏类型 | 国产模型支持 |
| :--- | :--- | :--- | :--- |
| 🟩 **像素风 (Pixel)** | 块状边缘、低分辨率、显性锯齿 | 平台跳跃、RPG、模拟经营 | ✅ 阿里百炼通义万相 |
| 🎨 **扁平风 (Flat)** | 纯色块、简洁线条、无渐变 | 休闲游戏、教育游戏 | ✅ 阿里百炼通义万相 |
| 🖌️ **日系动漫风 (Anime)** | 勾线+上色、大眼睛、柔和高光 | JRPG、视觉小说 | ✅ 阿里百炼通义万相 |

### 3.2 模型选型

| 维度 | 选择 | 原因 |
| :--- | :--- | :--- |
| **平台** | 阿里百炼（通义万相系列） | 便宜、速度快、有免费额度 |
| **调用方式** | REST API | Next.js API Routes 直接调用 |
| **成本控制** | 模型缓存 + 同 Prompt 去重 | 相同 prompt 不重复调用，自动缓存结果 |

## 4. 素材类型支持

### 4.1 用户输入 Prompt 模板化

| 素材类型 | Prompt 模板示例 |
| :--- | :--- |
| 🧑 **角色** | `[风格] 一个手持[武器]的[职业]，全身站立，[配色]` |
| 👾 **怪物** | `[风格] 一个[主题]风格的怪物，[特征]，站立姿态` |
| 🏞️ **场景** | `[风格] 一个[环境]背景，[色调]，[氛围]` |
| 🧱 **Tilemap** | `[风格] 一个[类型]地图瓦片，[特征]，可无缝拼接` |
| 🔪 **道具** | `[风格] 一个[物品]，[特征]，游戏道具图标` |
| 🖼️ **UI** | `[风格] 一个[功能]按钮，[颜色]，游戏UI元素` |
| 💥 **特效** | `[风格] 一个[类型]特效，[颜色]，透明背景` |

> 前端提供模板填空，降低用户输入门槛。

## 5. 用户体验流程

```
用户打开 GisFy 网页
    │
    ├── ① 选择素材类型（角色/场景/道具/...）
    ├── ② 选择风格（像素/扁平/日系）
    ├── ③ 填写文字描述（或选模板填空）
    ├── ④ 调节参数（尺寸/数量/Seed/负面词）
    │
    ▼
  点击「生成」
    │
    ▼
  AI 生成中...（加载动画 + 预计时间）
    │
    ▼
  生成完成 → 大图预览（展示费用 & 耗时）
    │
    ├── ✅ 满意 → 下载 / 存入历史（自动上传七牛）
    └── ❌ 不满意 → 调整 prompt 重新生成（免费重试）
```

## 6. 商业价值 & 比赛亮点

### 6.1 黑客松得分点

| 评分维度 | GisFy 策略 |
| :--- | :--- |
| 🎯 **完成度** | P0+P1 全部实现，功能闭环可演示 |
| 💡 **创新性** | 国产模型 + 游戏素材垂直场景，差异化明显 |
| 🛠️ **技术难度** | AI 生成 + Spritesheet 合成 + 对象存储全链路 |
| 🎨 **用户体验** | 模板化输入降低门槛，一键导出即用 |
| ☁️ **七牛生态** | Kodo 存储 + CDN 分发，深度绑定七牛 |

### 6.2 与七牛云的结合

```
阿里百炼（AI 推理）
    │ 生成图片
    ▼
GisFy 后端（Next.js 16 API Routes）
    │ 上传
    ▼
七牛 Kodo（对象存储） ← 白嫖免费额度
    │ CDN 加速
    ▼
用户浏览器（查看/下载素材）
```
