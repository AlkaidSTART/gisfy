GisFy 的 harness 用需求、PRD、技术设计、API 契约、Agent 规则、当前进度和质量门禁约束开发过程，让三天黑客松不是堆功能，而是从赛题到可演示产品的闭环。

一眼看懂：harness 解决什么

范围

架构

把 AI 生成纳入任务系统

生成请求、状态轮询、队列、存储和素材仓库分层，避免按钮直连模型。

协作

主代理控制方向，子代理按需读取

答辩

把过程讲成证据链

从赛题原文到实现文件和验证命令，每个关键决策都有落点。

答辩口播

GisFy 的工程亮点不只是调用模型，而是把 AI 生成纳入 2D 游戏素材生产链路。我们用 harness 先把赛题要求拆成 PRD、技术设计和 API 契约，再用 AGENTS、direction 和 context 控制 AI 辅助开发的边界。实现上，生成是异步任务，前端轮询状态；素材进入历史仓库；多帧可以合成 Spritesheet，并导出 PNG、JSON 和 manifest。七牛 Kodo/CDN 是目标存储和分发层，开发期提供 Supabase/base64 fallback 保证演示稳定。这套 harness 让三天黑客松的开发过程可追踪、可复盘、也可答辩。
